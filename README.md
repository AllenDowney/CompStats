# Computational Statistics

Code for a workshop on statistical inference using computational methods in Python: effect sizes, sampling distributions, and hypothesis testing with resampling and simulation.

I presented it at PyCon US 2015 and 2016 and at SciPy 2015 and 2017. The most recent recording is [SciPy 2017](https://www.youtube.com/watch?v=He9MCbs1wgE); earlier ones are from [PyCon 2016](https://www.youtube.com/watch?v=VR52vSbHBAk), [PyCon 2015](https://www.youtube.com/watch?v=5Vjrqnk7Igs), and [SciPy 2015](https://www.youtube.com/watch?v=fMycLa1bsno).

This is one of [my workshops and tutorials](https://allendowney.github.io/#workshops).
